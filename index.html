git add : 1. “git add .”: usando un punto, esta opción añadiría todos los cambios en archivos, excepto en aquellos que han sido eliminados. 2. “git add -u”: añadiría solo los archivos existentes con cambios. 3. “git add *.extensión”: añadiría solo los archivos con una determinada extensión; por ejemplo, “git add *.js”.
